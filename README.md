This contains four individual capstone projects

**portugese bank**
The data is related with direct marketing campaigns of a Portuguese banking institution. The classification goal is to predict if the client will subscribe to a term deposit.

**rice leaf**
The dataset contains images of rice leaf. There are three classes/diseases: Bacterial leaf blight, Brown spot, and Leaf smut, each having 40 images. The format of all images are jpg.

**fifa 20**
Using clustering algorithms to categorize similar players using their traits and their different skills in the field.

**flight price prediction**
Uisng the dataset need to predict fare of flight
